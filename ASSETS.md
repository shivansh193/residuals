# Assets and consent

## Demo voices

Decision (2026-11-10): **fully synthetic voices only.** No real person's voice is used, recorded or cloned.

- Each demo "voice owner" is a fictional persona whose voice is designed from a text description with an open TTS model (not cloned from any real recording).
- The "AI clone" of each persona is made with an open zero-shot cloning model, run on a Kaggle GPU (no local model runs), using only that persona's synthetic reference audio.
- No celebrity, public figure or third-party recording is used anywhere.
