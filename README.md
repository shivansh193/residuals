# Residuals

Royalties for licensed AI voice clones, paid through PayPal.

A voice owner enrols their own voice with a consent recording and a liveness check, then sets terms in plain English. Residuals detects that voice in submitted audio (including AI clones), meters the minutes, bills the user with a PayPal invoice, and pays the owner's royalty by PayPal Payout when the invoice is paid.

**The one rule: consent first.** Only voices whose owners enrolled themselves can be registered.

Work in progress for the PayPal AI Hackathon. See [docs/SPIKES.md](docs/SPIKES.md).
